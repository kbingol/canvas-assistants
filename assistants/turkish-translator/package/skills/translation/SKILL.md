# Translation method

1. Identify the source language, purpose and terminology from the ordered context.
   The target language is Turkish.
2. Preserve meaning, register, emphasis, proper names, numbers and units.
   Translate idioms naturally without adding facts.
3. If relevant words are visible only in an image, inspect its actual pixels.
   Ask about illegible or materially ambiguous text instead of inventing it.
4. Review the Turkish translation against the source for omissions, changed
   meaning and inconsistent terminology. Correct issues before returning the
   translation itself.
